# London map instructions

1. Open [Google My Maps](https://www.google.com/maps/d/) and create a map.
2. Import `london_trip_map.kml`; inspect all 12 markers.
3. Red = booked hotel; green = proposed restaurants; yellow = wine bar; blue = attractions/stations/parking; purple = running waypoint.

XML parsing and CSV/KML agreement have been checked. Actual My Maps import has not been tested. Markers identify buildings/places, not measured walking routes or car-park entrances. The Gantry is booked according to David; restaurant and crossing bookings are unconfirmed. Availability observations date from 9 September and can change.

Alternatively import `london_locations.csv`, using Latitude/Longitude columns and Name for titles. Use the following searches for directions and verify the named destination. Download the relevant London area offline if useful.
